# Hangman Word Guessing Game

## About the Project

This is a console-based Hangman word guessing game developed using Python as part of the Datheon Python Programming Internship.

The player tries to guess a randomly selected English word one letter at a time, within six incorrect attempts.

## Features

- Random word selection from a predefined word list
- Hidden word displayed using underscores
- Interactive letter-by-letter guessing
- ASCII gallows art that updates with each incorrect guess
- Maximum of six incorrect attempts
- Tracking of correctly and incorrectly guessed letters
- Input validation for invalid entries
- Duplicate guesses do not deduct attempts
- Win and lose conditions with clear messages
- Option to play again

## Technologies Used

- Python 3
- Visual Studio Code
- Python Standard Library (`random` module)

## How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the `Task_1_Hangman_Game` folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python hangman.py
```

## How to Play

1. Run the game.
2. Guess one letter at a time.
3. Correct guesses reveal the letters in the hidden word.
4. Incorrect guesses update the Hangman drawing.
5. You have six incorrect attempts.
6. Guess the complete word to win.
7. Choose whether to play again after the round ends.
